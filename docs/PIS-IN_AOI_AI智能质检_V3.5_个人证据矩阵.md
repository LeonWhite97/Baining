## 高频追问简答

**为什么 Agent 不直接判 PASS？** 实时检测需要确定性、低延迟、可回退；Agent 只做解释、检索和报告草稿，最终结论由规则和人在回路控制。

**人工复核与人在回路区别？** 人工复核是 REVIEW 队列中的具体操作；人在回路是系统级责任边界，覆盖放行、报告批准、模型发布、金标准回流和异常处置。

**为什么先 YOLOv8s？** 以边缘资源和实时性为约束的基线。是否升级 v8m/l/x 由小缺陷召回、关键缺陷漏放和 P95 数据决定，而不是盲目追求大模型。

**为什么不采用 Handler 自动化？** 当前项目先验证单机检测、数据关联、模型决策和质量闭环。过早引入 Handler 握手、实时 BIN 回传和跨设备状态机会扩大联调范围；因此接口研究成果保留，但默认关闭，待业务明确需要自动上下料和分选时再独立立项。
